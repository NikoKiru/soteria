Updates

Latest features, improvements, and fixes for Soteria.

April 3, 2026 Feature

Inline Password Generator on Signup Pages

The browser extension now detects signup and account-creation forms and shows a Generate button directly next to the password field.

  • One-click generation — clicking the button fills the password field (and any confirm-password field) with a strong 20-character password
  • Clipboard copy — the generated password is automatically copied to your clipboard
  • Auto save prompt — after completing the signup form, Soteria immediately prompts you to save the credentials (no delayed heuristic needed since the password was generated by Soteria)
  • Signup detection — uses the same heuristics as the save-prompt (confirm-password fields, URL patterns, form text) to only appear on registration flows
  • SPA support — the button is re-injected after dynamic navigation and DOM changes
April 1, 2026 Bug Fix Security

Input Validation Hardening & Vault Integrity Fixes

A code audit uncovered several validation gaps and robustness issues, now resolved:

  • Duplicate username prevention on update — update_entry now checks for duplicate service+username combinations before saving, matching the guard already present in add_entry
  • CLI update length validation — the update command now validates field lengths (service, username, password, URL, notes) before writing, closing a gap where oversized data could be saved
  • GUI entry dialog length limits — the add/edit dialog now enforces maximum field lengths (100/255/1024/2048/10000 chars) with inline error messages
  • Atomic rate-limit file writes — rate-limit state now uses temp-file-then-replace, consistent with vault file writes, preventing corruption on crash
  • Legacy vault upgrade notification — when a vault encrypted with older Argon2id parameters is opened and auto-upgraded, users now see a toast notification (GUI) or log entry (CLI) confirming the upgrade
  • Service index guard — update_entry now correctly rebuilds the service index if the service name changes, preventing stale lookups
  • Extension alphabetical sorting — the browser extension entry list is now sorted alphabetically by service name (then username), so newly added entries appear in the correct position instead of at the bottom
February 8, 2026 Improvement Security

Comprehensive Test Suite — 97% Code Coverage

Built a professional test suite from the ground up, covering every module with 274+ automated tests and 97% line coverage:

  • 274 tests across 8 modules — vault operations, CLI commands, IPC server endpoints, cryptography, storage, models, password strength, and logging
  • 97% line coverage — all non-GUI code is thoroughly tested with branch-level verification using pytest-cov
  • Rate limit isolation — test fixtures redirect rate-limit state to temporary directories so tests never bleed state or affect real vault data
  • IPC server integration tests — 55 tests exercise the browser extension API including CORS preflight, domain search, all entry endpoints, and error handling
  • CLI command coverage — 82 tests cover every subcommand including init, add, get, list, delete, search, update, change-master, and generate with all their edge cases
  • Slow test marker — Argon2id key derivation tests are marked @pytest.mark.slow so fast iteration skips them with -m "not slow"
February 7, 2026 Bug Fix Improvement

Shutdown Fix, Landing Page Redesign & README

A bug fix for the shutdown shortcut, a complete landing page overhaul, and new project documentation:

  • Ctrl+Q fix — resolved a crash caused by a missing sys import that prevented the app from shutting down; each cleanup step is now independently guarded so one failure can't block the rest
  • Landing page redesign — reduced from 15 sections to 10, replaced all emoji icons with inline SVGs, rewrote copy, added tabbed screenshot gallery, merged comparison table into a card layout, and added prefers-reduced-motion support
  • Root README.md — added a comprehensive project README with features, quick start, CLI reference, security summary, and contributing guidelines
  • Keyboard shortcuts on Get Started — relocated the shortcuts reference from the landing page to the Getting Started guide where it's more useful
  • Emoji cleanup — replaced remaining HTML-entity emojis on the Getting Started page with SVG icons

January 31, 2026 New Feature

Browser Extension & Headless Service

Soteria now includes a Chromium browser extension and a headless background service for seamless password autofill.

  • Search and autofill passwords directly from Chrome, Edge, or Brave
  • Domain-matched suggestions appear automatically on login pages
  • Unlock your vault from the extension popup
  • Headless service runs in the background and auto-starts on login
  • Add new passwords from the extension with one click
January 15, 2026 Security

Enhanced Security Defaults

Security improvements to ensure your vault is always protected:

  • Argon2id parameters increased: 128 MB memory, 4 iterations
  • "Never" option removed from auto-lock and clipboard clear timers
  • Secure clipboard overwrite with random data before clearing
  • Rate limiting with exponential backoff after 5 failed unlock attempts
January 1, 2026 New Feature

Initial Release - Soteria v1.0.0

The first public release of Soteria, a secure local-first password manager.

  • AES-256-GCM encrypted vault with Argon2id key derivation
  • Modern GUI with system tray and global hotkey support
  • Full-featured CLI for scripting and automation
  • Password generator with configurable length and character sets
  • Auto-lock, clipboard clearing, and secure file permissions
