# Soteria Wiki

Soteria is a secure, local-first password manager with GUI, CLI, and browser extension support.

This wiki is the fastest way to learn how to install, use, secure, and troubleshoot Soteria.

## What Soteria Focuses On

- Local-first architecture (no cloud requirement)
- Strong encryption: AES-256-GCM + Argon2id
- Fast workflows via GUI and CLI
- Safe browser autofill via localhost IPC

## Important Security Note

The browser extension cannot unlock your vault. You must unlock the vault in the desktop app.
